# Code additions archive

`PPP_code_tests_additions.zip` is the original code-and-test bundle. It contains
`files/` with added or corrected files, `report_preparation.patch`, and
`INSTALL.md`. The canonical source files are already in this repository under
`../Project implementation plan (2)/` and `.github/`.

The repository's `run_tests.sh` and `run_tests.pbs` intentionally remain the
repository-specific versions: they use this archive's RVE artifact paths and
cluster environment setup. The zip copies are retained for comparison, not as
a direct replacement.
