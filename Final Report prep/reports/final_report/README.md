# PPP final report (TUBAF template) - revised 18 Nov 2026

Build (Overleaf: upload the whole zip, main document `main.tex`, compiler pdfLaTeX):

    pdflatex main && bibtex main && pdflatex main && pdflatex main

Contents
- `main.tex`, `metadata.tex`, `frontmatter/`, `chapters/`, `appendices/`, `references.bib`
- `tubaf-report.cls`, `tubaf_src/` - official TU Freiberg class (unchanged)
- `figures/` - all figures (vector PDF), regenerated by `python figure_sources/make_figures.py`
- `figure_sources/` - plotting script, analysis scripts (split_metrics.py, prep_record_data.py, parse_macro_logs.py) and all extracted data
- `code_patches/` - code corrections/additions made while preparing the report:
  `report_preparation.patch` (apply inside "Project implementation plan (2)" with `patch -p1 < report_preparation.patch`),
  the changed files themselves in `files/`, and the logs of the independent re-execution in `test_logs/`
