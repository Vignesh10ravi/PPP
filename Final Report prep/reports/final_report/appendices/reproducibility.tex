\paragraph{Final-run hash collection.}
The final shear data and macro-FE outputs were generated after the earlier
cluster export. Their file hashes must be collected from the final run before
submission; the manifest also records the dataset, configuration, and source
revision hashes. On the cluster, run:
\begin{lstlisting}[language=bash]
sha256sum \
  /scratch4/vr80beqo/rve_shear_final_holdout_20261116/data/rve_shear_final_holdout.npz \
  /scratch4/vr80beqo/rve_shear_final_holdout_20261116/data/rve_shear_final_holdout.manifest.json \
  /scratch4/vr80beqo/rve_shear_final_holdout_20261116/evaluation/shear_final_holdout_report.json \
  /scratch4/vr80beqo/rve_phase7_macro_fe_selected_shear_20261116/report.json \
  /scratch4/vr80beqo/rve_phase7_macro_fe_selected_shear_20261116/comparison.json \
  /scratch/vr80beqo/rve_shear_adaptation_finetune_20261115/partial_icnn_phase7_shear_adapted.pt
python - <<'PY'
import json
path = "/scratch4/vr80beqo/rve_shear_final_holdout_20261116/data/rve_shear_final_holdout.manifest.json"
manifest = json.load(open(path, encoding="utf-8"))
for name in ("dataset_sha256", "configuration_sha256", "source_revision_sha256"):
    print(f"{name}: {manifest.get(name)}")
PY
\end{lstlisting}

\section{Git log}

The final report must include the project history required by the PPP
guideline. Generate the frozen log with:
\begin{lstlisting}[language=bash]
git log --date=short \
  --pretty=format:"%h %ad %an %s" \
  > reports/final_report/git-log.txt
\end{lstlisting}

No \texttt{.git} directory or frozen Git-log artifact was present in the
cluster export. The manifest \texttt{source\_revision\_sha256} values are
content revisions, not demonstrably Git commits, and are therefore not
substituted for the required history. The Git log remains a release task.
