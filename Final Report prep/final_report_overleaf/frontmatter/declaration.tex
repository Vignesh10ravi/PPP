responsibility for this Personal Programming Project are my own. External

numerical-test design, code and documentation review, and preparation of
report structure and language. AI-generated suggestions were treated as
untrusted proposals: relevant changes were checked against equations,
software documentation, executable tests, or independent numerical evidence.

in \cref{ch:ai-tools}.
